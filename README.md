## Featured Projects

- **[Agentic-Codebase-Explainer](https://github.com/Nandish-Karki/Agentic-Codebase-Explainer)** (Just shipped!)
  
  A 6-agent CrewAI crew that reads any software project folder and generates instant structured explanations: architecture diagrams, file maps, API endpoints, dependencies, risks, and a 5-minute demo script. Powered by Groq (70B Mixtral) + LiteLLM for cost optimization.
  - Stack: CrewAI, Groq API, LiteLLM, Python, UV

- **[Agentic-Study-Planner](https://github.com/Nandish-Karki/Agentic-Study-Planner)**
  
  5-agent CrewAI crew that reads CVs, academic transcripts, target career roles, and module handbooks (real PDFs) to generate grounded semester-wise study plans. Parallel analysts + tool-less synthesis agents prevent hallucination.
  - Stack: CrewAI, Groq API, PyPDF2, GitHub API, LiteLLM, Python

- **[AI-Based-Learning-Assistant](https://github.com/Nandish-Karki/AI-Based-Learning-Assistant)**
  
  Full-stack RAG platform: React + Tailwind frontend, Flask backend, Gemini 2.5 Flash for Q&A, LLaMA 3.2 for module generation, ChromaDB + SentenceTransformers, Firebase auth, AWS Polly SSML narration.
  - Stack: React, Flask, Gemini, LLaMA, ChromaDB, Firebase, AWS Polly

- **[LISA - Speech-to-Speech Translation](https://github.com/Nandish-Karki/speech-to-speech-translation)**
  
  Real-time multilingual speech translation: faster-Whisper ASR → OPUS-MT incremental translation → Coqui TTS. Supports 6 language pairs (EN↔DE/ES/FR). Docker microservices targeting p95 latency <30s.
  - Stack: faster-Whisper, OPUS-MT, Coqui TTS, Docker, Python

  - Stack: PyTorch, CNN, Gradio, Docker, Python

- **[NYC Airbnb Dashboard](https://github.com/Nandish-Karki/nyc-airbnb-dashboard)**
  
  Multi-page Streamlit analytics on 49K+ listings (2019). Interactive geospatial maps, OLS regression, correlation heatmaps, price distribution analysis. Key finding: room type is the strongest pricing predictor.
  - Stack: Streamlit, Pandas, Statsmodels, Plotly, Python
